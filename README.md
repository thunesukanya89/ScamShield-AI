# ScamShield AI 🛡️

ScamShield AI is a web application that uses artificial intelligence to analyze suspicious messages and identify potential scams.

## Features
- AI-powered message analysis
- HIGH, MEDIUM, and LOW risk levels
- Scam warnings and safety advice
- Scan history

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- Ollama and Llama 3.2

## How to Run

1. Install Python and Ollama.
2. Install the dependencies:

   python -m pip install -r requirements.txt

3. Download the AI model:

   ollama pull llama3.2

4. Start the application:

   python app.py

5. Open http://127.0.0.1:5000/ in your browser.

## Disclaimer
AI analysis can make mistakes. Always verify suspicious messages independently.
